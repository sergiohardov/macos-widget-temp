# TempBar

Лёгкий виджет для строки меню macOS (там же, где часы), показывающий температуру
**CPU / GPU / батареи / накопителя / корпуса**. Написан на нативном Swift,
рассчитан на Apple Silicon (M1).

## Как это устроено

- Читает датчики через `IOKit` → службу `AppleSMC` (SMC-ключи `Tp*`, `Tg*`, `TB*`, `TH*`, `Ts*`).
- **Только чтение.** Приложение ничего не пишет в SMC, не требует root, не ставит
  расширений ядра и никак не модифицирует систему.
- Работает как агент (`LSUIElement`): нет иконки в Dock, только значок в статусбаре.

## Сборка и запуск

```bash
# собрать .app-бандл
./build-app.sh

# запустить
open dist/TempBar.app
```

Либо для разработки:

```bash
swift run -c release
```

### Автозапуск при входе в систему (по желанию)

System Settings → General → Login Items → добавить `dist/TempBar.app`.

## Что показывает

- **В статусбаре:** для каждой выбранной метрики — отдельная колонка в две строки:
  температура с символом `°` сверху и подпись (`CPU`, `GPU`, `BAT`, `SSD`, `ENC`) снизу.
  Если ничего не выбрано — иконка-термометр, меняющая вид/цвет по самой горячей зоне.
- **В меню (по клику):**
  - переключатели метрик (CPU / GPU / Батарея / Накопитель / Корпус) — отмеченные
    показываются в статусбаре;
  - «Отображать историю замеров» — включает пункт с нарисованным графиком истории;
  - интервал обновления (1/2/5/10 сек);
  - Выход.

## Возможности

- **Группы датчиков (M1):** CPU (`Tp*`), GPU (`Tg*`), батарея (`TB*T`),
  накопитель/NAND (`TH0a/b/x`), корпус/ambient (`Ts0P/1P`). По каждой группе берётся
  **медиана** — устойчива к одиночному «битому» датчику.
- **Фильтр выбросов:** нефизичные мгновенные провалы температуры (артефакты чтения SMC,
  напр. 49→9) отбрасываются — держится предыдущее значение.
- **Подсветка перегрева:** значение в статусбаре жёлтое при `≥80°`, красное при `≥95°`.
- **Уведомления о перегреве:** разовое уведомление при `≥95°` по группе, повторно — только
  после остывания ниже `90°` (гистерезис, без спама). Пороги — константы в начале
  `AppDelegate.swift`.
- **График истории:** лёгкая отрисовка через `NSBezierPath` (без картинок), линия на
  каждую метрику своим цветом, последние 30 замеров.
- **Иконка-индикатор:** в режиме без выбранных метрик термометр меняется
  `low/medium/high` + жёлтый/красный тинт по самой горячей зоне.
- **Выбор сохраняется** между запусками (`UserDefaults`).

## Лёгкость / влияние на систему

- На таймере читаются только 5 групп датчиков (а не все ~170 сенсоров SMC).
- **Меню строится лениво** — только в момент открытия, а не каждый тик.
- **Пауза при сне дисплея/системы** (`NSWorkspace`): когда экран погашен, опрос
  полностью останавливается и возобновляется при пробуждении.

## Заметка про «материнскую плату»

На Apple Silicon отдельного датчика материнской платы нет — CPU, GPU, контроллеры
и память находятся в одном кристалле (SoC). Ближайшие аналоги «температуры платы» —
батарея и корпусные/ambient-датчики (метрики «Батарея» и «Корпус»).

## Уведомления

При первом запуске macOS запросит разрешение на уведомления. Если запрос не появился —
включите вручную в System Settings → Notifications → TempBar. Без разрешения подсветка
и иконка работают, а всплывающие уведомления — нет.

## Структура

- `Sources/TempBar/SMC.swift` — низкоуровневое чтение SMC через IOKit.
- `Sources/TempBar/Sensors.swift` — группы ключей, медиана, фильтр выбросов, история.
- `Sources/TempBar/AppDelegate.swift` — статусбар, меню, таймер, подсветка, уведомления.
- `Sources/TempBar/GraphView.swift` — отрисовка графика истории.
- `Sources/TempBar/main.swift` — точка входа.
